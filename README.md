## 🚀 Overview

**Guida** is a cross-platform mobile application built with  **Flutter** and **Dart** that redefines campus navigation. It eliminates **confusing maps and time-consuming detours by providing a simple, direct path to any lecture hall or department office.** The project showcases advanced skills in **Robust State Management, Seamless REST API Integration** and demonstrates my ability to build **scalable, visually appealing applications**  for iOS and Android.

### Key Features ✨

* **Secure User Authentication:** *Implemented a robust login and sign-up system using Firebase Authentication, allowing users to create personalized profiles and sync their saved locations across devices.*
* **Interactive Campus Maps:** *Seamlessly integrated the Google Maps SDK to render a detailed, interactive map of the university campus, providing a familiar and responsive base layer for all navigation.*
* **Intelligent Route Calculation & Navigation:** *Engineered a core feature that calculates the optimal walking path from the user's live GPS location to any selected destination on campus (e.g., "Engineering Building, Room 301"). The app provides visual and textual turn-by-turn directions.*
* **Campus-Specific Points of Interest (POIs):** *Curated a list of key campus locations—including academic buildings, lecture halls, administrative offices, and libraries—making them easily searchable and selectable for instant navigation.*
